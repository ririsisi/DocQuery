# 开源软件准入（仿制度）

> 模拟流程说明，非生产原文。本系统只建单、展示对端送来的信息和走审核，不做软件包内容校验。

## 谁发起

建设方系统（软件交付台）上，用户上传开源软件包后调运管平台建单。附件（如安全扫描报告）由建设方侧存储拉取，不在本系统重传一份源码仓库。

## 审核链

1. 安全管理员审核。
2. 开源软件负责人审核。负责人可以结束流程（回写建设方、并送配置库审核数据），也可以提交给领导继续审。
3. 领导会签：需求侧领导 + 安全侧领导，两人都会签。
4. 再回到开源软件负责人，结束流程并回写建设方、送配置库。

运管平台另提供建设方查询工单状态的接口。本系统不负责包合法性、许可证扫描等校验，那些在建设方完成。
