# 厂商主数据同步接口（仿，干扰稿）

> 模拟另一套供应商主数据接口。字段名和入职开账号、人员同步很像，含义不同。不提供真实主机或内网域名。

## 接口

- 名称：厂商主数据同步
- 功能：把供应商档案从主数据推到运管
- 方法：POST
- 路径：`/api/external/vendor/syncMaster`
- 请求/响应：application/json

## 请求参数

| 参数 | 含义 | 类型 | 必填 |
|------|------|------|------|
| applyUser | 申请人中文名，仅作备注 | String | 否 |
| sourceSystem | 主数据系统编码 | String | 是 |
| items | 供应商列表 | Array | 是 |

调用系统标识示例：`VENDOR_HUB`。

## items 对象

| 参数 | 含义 | 必填 |
|------|------|------|
| vendorName | 供应商对外显示名，可与合同主体不一致 | 否 |
| vendorCode | 主数据编码 | 是 |
| contactMobile | 接口人手机 | 否 |

本文的 vendorName 是选填显示名，不是入职开主账号里的合作商必填项。applyUser 也不是提交人账号。
