# 统一用户创建主账号接口（仿）

> 模拟接口说明。不提供真实主机、IP 或内网域名。样例身份证与手机号均为虚构。

## 接口

- 名称：入职接口
- 功能：统一用户对外批量创建主账号
- 方法：POST
- 路径：`/api/external/user/batchCreate`
- 请求/响应：application/json

## 请求参数

| 参数 | 含义 | 类型 | 必填 |
|------|------|------|------|
| applyUser | 提交人/操作人账号，用于审计与接口权限校验 | String | 是 |
| sourceSystem | 调用系统标识 | String | 是 |
| items | 入职人员列表 | Array | 是 |

调用系统标识示例：`UNIFIED_IAM`。

## items 对象（均为必填）

| 参数 | 含义 |
|------|------|
| usercn | 姓名 |
| idCardNumber | 身份证号码 |
| preferredMobile | 手机号 |
| email | 邮箱 |
| jobDuty | 工作职责 |
| jobPlace | 工作地点 |
| isPresent | 是否现场办公 |
| contractNo | 合同编号 |
| vendorName | 合作商名称 |
| vendorId | 合作商 ID |
| supervisor | 局方接口人账号 |
| macAddress | 终端 Mac 地址 |
| serviceCategory | 服务类别：软件研发 / 技术支持 / 维保 / 投资建设 |
| expireDate | 账号失效时间 |

## 返回

| 字段 | 含义 |
|------|------|
| code | 响应码 |
| message | 汇总说明，如「批量处理完成」 |
| workId | 工单号 |
| results | 逐条结果 |

单条失败时 results[].message 给出原因，例如「手机号校验失败，仅支持移动号码」。成功条目标 message 为空。一批中允许部分成功、部分失败。
