# 结算付款管理（仿制度）

> 模拟流程说明，非生产原文。查询条件可按合同编号、订单筛选。符合条件的由厂商负责人勾选结算月份、确认金额后发起申请。

## 主流程

厂商负责人发起 → 局方项目负责人审批 → 结算付款操作员付款提交并结束后勾选关闭，状态为「已付款」。可驳回后重新发起。

## 预估、固定合同

1. 非人天结算项目：系统判断关联月份的工时核算、日常考核均已关闭，才能发起；流转到局方项目负责人，展示汇总待结算金额。
2. 人天结算项目：还须关联月份的人员投入盘点、工时核算、日常考核均已关闭。流转到局方项目负责人后，须其手工确认已完成「协作结算台」工作量结算单推送，并手工输入实付金额（不得高于系统计算的待结算金额），才能到结算付款操作员。

## 框架合同

1. 非人天结算项目：关联月份的工时核算（第三方工时评估流程）和日常考核须已关闭。局方项目负责人确认省侧采购供应链「费用结算单」已审批后，转到结算付款操作员。
2. 人天结算项目：人员投入盘点、工时核算、日常考核须已关闭。局方项目负责人须确认：协作结算台工作量结算单已推送；协作结算台工作量与运管平台工时核算工单结算额度一致；省侧采购供应链「费用结算单」已审批。然后转到结算付款操作员。
