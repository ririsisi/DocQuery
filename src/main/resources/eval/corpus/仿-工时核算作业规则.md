# 工时核算作业规则（仿制度）

> 模拟流程说明，非生产原文。出单时点以「第三方工时核算」仿制度的 22 号规则为准；老交接曾写每月 1 号建当月工时单，现网需求已改成与日常考核同一套日期逻辑。

## 审批怎么走

厂商审核完成之后：

- 项目负责人与核算管理员是同一个人：工单送给外包审核。
- 不是同一个人：工单送给项目负责人审核。

核算管理员在各个环节都可以撤回工单。

0 工时的主管审批改为自动通过，不必领导再点。系统在每月 21 号给主管发阅知邮件，列出本月已自动审批的 0 工时 / 0 扣款活动。

## 线上、线下、是否抽样

多数部门当前以线下核算为主。

- 软件优化类-线上：导入总样核算 → 抽样 → 导入抽样核算结果 → 生成会议纪要。
- 软件优化类-线下：导入总样核算 → 抽样核算结果 → 生成会议纪要。
- 非软件优化类：导入总样核算 → 生成会议纪要，不抽样。

核算工作量 = 评估总工作量 × 抽样总工作量 / 抽样总评估工作量。

会议纪要不再直接生成 PDF 附件，而是在附件区给下载链接。管理员填写时间、地点、参与人员后保存。软件优化类且赠送比例大于 0、等于 0、以及非软件优化类，使用不同纪要模板。

工时清单 Excel 是否在附件中展示，由开关控制。

## 与供应链计提校验

订单对应的计提额度从采购供应链取回。提交工时核算时，结算金额与计提金额的差值必须在正负 3% 以内（含等于计提金额本身）。超出则提示：结算金额和计提金额的差值只能在 3% 以内，请修改结算金额。

结算工时为 0 且结算金额为 0 的结算单，仍推送采购供应链。

## 厂商人员台账

新增厂商人员以身份证为唯一判断条件。同一人员在同一个月份只能维护一次。打开工单时自动带出上次填写的人员。

生成人员工单时：有厂商负责人则派给厂商负责人填；没有（临时负责人空缺）则派给项目负责人填。流程：厂商负责人填写确认 → 项目负责人审核。
