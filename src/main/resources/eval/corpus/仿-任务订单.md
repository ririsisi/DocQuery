# 任务订单与关联合同（仿制度）

> 模拟流程说明，非生产原文。打印、审批等跳到采购供应链办理的页面，不在本模块重做。

## 何时建单

业务活动进入「执行中」之后，由外包管理员关联合同、新建任务订单。

选择合同时系统校验：合同剩余金额与订单剩余金额、合同周期与订单周期。业务活动编号、物料编码来自采购供应链同步，不手工编造。

## 框架与单项

- 框架订单：关联合同并同步采购供应链。页面展示同步相关字段。
- 单项（非框架）：也可以关联合同、生成订单，但只保存、不同步采购供应链。页面隐藏「同步供应链」。业务活动编号、物料编码可为空或填「无」。单项订单同样参与未圈金额计算，其工时核算单、日常考核单挂在该订单下。

省公司任务订单按自然年 12 个月；地市订单允许跨年。

十二个月「是否框架」的展示，跟任务订单属性走，不是跟业务活动口头说法走。

## 任务订单状态（业务关心的几个）

生成考核和工时单时，订单须达到「采购供应链已下达」及之后状态（含到货、关闭等后续态）。已保存、同步异常、供应链退回、已取消，不能当做出单条件。

## 考核版本

考核版本在「考核版本管理」单独维护。外包管理员按五种订单类型分别导入考核项，同一版本号对应五条。

- 省公司 / 创新院：关联合同时选择考核版本，生成考核单时写入工单。
- 地市订单从供应链同步、本身无版本号：管理员提交业务活动时，按订单类型和合同开始年份取该年最大版本号写入。之后订单再同步，仍按合同开始年与订单类型重设版本号。

## 人天单价

人天单价、赠送工时抵扣比例在合同管理维护，随合同从供应链同步。任务订单默认带出合同上的单价和赠送比例，管理员可以改。分档可以是专家 / 初级 / 高级 / 普通，或 A/B/C/D 类。
