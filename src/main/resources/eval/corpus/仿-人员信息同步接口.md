# 统一用户人员信息同步接口（仿）

> 模拟接口说明。不提供真实主机、IP 或内网域名。调用方用配置中的 base-url，不把地址写进业务代码。

## 接口

- 名称：信息同步接口
- 功能：从统一用户拉取人员信息
- 方法：POST
- 路径：`/api/external/user/syncUserInfo`
- 请求/响应：application/json

## 请求参数

| 参数 | 含义 | 类型 | 必填 |
|------|------|------|------|
| sourceSystem | 调用系统标识 | String | 是 |

调用系统标识示例：`DOC_OPS`（运管平台）。

## 返回

| 字段 | 含义 |
|------|------|
| code | 响应码，成功为 200 |
| message | 处理结果说明 |
| items | 人员列表 |

items 对象：

| 字段 | 含义 |
|------|------|
| userId | 账号（不是中文姓名） |
| status | 0 正常；1 锁定；2 禁用；3 离职 |
| preferredMobile | 手机号 |
| email | 邮箱 |
| supervisor | 局方接口人账号 |
| contractNo | 合同编号 |

## 调用样例

请求：`{"sourceSystem":"DOC_OPS"}`

成功时 items 中可同时出现在职（status=0）与离职（status=3）人员，调用方按状态更新本地账号，不得把已离职账号继续当有效用户。
