# 研效类工单（仿制度）

> 模拟流程说明，非生产原文。用于研发效能领域里「非需求开发」类任务的分配和工时评估，不收录对端系统真实地址。

## 适用

研发效能督导、研发管理、自动化测试、测试环境、研发运营、需求运营、项目管理及运营、规划立项等，凡属非需求开发类工作，走本流程做任务分配和工时计算。菜单：需求管理 — 研效工单管理。页签：我的待办、我的已办、我的创建、工单查询、新建工单。新建权限给建设条线需求管理员。

## 环节

| 环节 | 角色 | 可做 |
|------|------|------|
| 任务新建 | 建设条线需求管理员 | 填单提交，工单正式生成 |
| 任务安排 | 网格长 | 转派、提交安排、取消 |
| 任务分配 | 网格开发经理 | 在协作任务台操作 |
| 任务处理 | 网格成员 | 在协作任务台操作 |
| 任务审核+评价 | 网格长 | 通过并填满意度，或不通过并写理由；可取消 |
| 任务关闭 | 系统 | 审核通过后关闭 |

处理中环节，待办挂在系统机器人名下。附件只能上传一份；多份须打包后再传，系统限制单附件。

## 网格长是不是本人

新建时「网格长」默认为空。

- 选的网格长就是当前登录人：须同时填网格名称、网格开发经理，提交后到开发经理，状态「待分配」。
- 选的网格长不是当前登录人：网格名称和开发经理不能改，提交后到该网格长，状态「待安排」。收到单的网格长可以转派给其他网格长、安排给自己名下开发经理、或取消。
- 只有网格长等于当前登录人时，才能改网格名称和开发经理。单子被退回后若网格长做了转派，这两个字段要置空。

## 取消

建单人或网格长都可以取消。只要工单还在正常流转，网格长可取消并填写原因。取消不是流程里的环节按钮，是表单上的全局动作（因为取消人经常不是当前待办人）。

运管平台侧取消、退回、审核时，把状态同步到协作任务台。一条工单从交到网格开发经理起开始同步；之后在运管平台的状态变化都要同步。
